# 从 jczte-dsh-knowledge 迁移

`Ltx_JC_RAG` 使用独立的插件 ID 和数据目录：`dshHomePath('ltx-jc-rag/')`。安装新插件不会读取、修改或删除旧插件位于 `dshHomePath('jczte-knowledge/')` 的 SQLite、连接配置或服务设置。

## 推荐步骤

1. 停止旧插件所在的 DSH profile，复制整个 `jczte-knowledge/` 目录作为备份。
2. 安装 `ltx-jc-rag`，确认新插件能够正常启动并创建新的空数据库。
3. 在旧插件管理台导出需要保留的知识文档，使用新插件管理台的导入功能导入。
4. 完成抽样检索和审核后，再决定是否卸载旧插件。

## 当前限制

本版本刻意不自动复制 SQLite 文件：自动迁移会把旧的会话挂载、远程连接和写入策略带入新插件，可能违背用户当前的隐私选择。后续会提供可预览、可回退的显式迁移向导。
